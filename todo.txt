We split memory into three different types:

  1. rolling user profile
      - compact, stable facts and preferences
      - useful for personalization
  2. daily summaries
      - recent episodic memory
      - useful for questions about prior days or ongoing threads
  3. recent turns
      - a tiny short-term window
      - useful for pronouns, approvals, and follow-ups

  The key rule was:

  - do not include all three by default
  - load them selectively depending on the request
